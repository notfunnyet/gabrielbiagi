## 🚀 Como rodar localmente

> Os comandos abaixo assumem um projeto Node.js. Adapte se o seu for diferente.

```bash
# Clonar o repositório
git clone https://github.com/[seu-usuario]/gabrielbiagi.git

# Entrar na pasta
cd gabrielbiagi

# Instalar as dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```

Depois, abra o endereço exibido no terminal (geralmente `http://localhost:3000` ou `http://localhost:5173`).
